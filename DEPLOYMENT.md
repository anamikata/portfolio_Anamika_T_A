# Deployment Guide — Anamika T A Portfolio

This update is a separate copy of the existing portfolio. It does not publish anything automatically.

## Replace the current GitHub Pages files

1. Keep a local copy of the current repository before replacing anything.
2. Extract this ZIP and open the `portfolio_Anamika-main` folder.
3. Replace the files in the GitHub repository with the contents of this folder, keeping the repository name and GitHub Pages settings unchanged.
4. Commit and push the changes to the branch currently used by GitHub Pages (commonly `main`).
5. Wait for GitHub Pages to rebuild, then open the existing portfolio URL and check the navigation, project links, certificate previews and mobile layout.

## Important

- This project is a static React/Babel site and does not require a build command or package installation.
- Keep `index.html`, `app.js`, `styles.css`, and the complete `assets/` directory together.
- Do not remove the certificate subfolders or the `assets/credentials/aws-ai-practitioner/` directory.
- The ASTHRA card is intentionally a reserved placeholder. Replace it with the actual certificate file when available.
- No GitHub repository or live website was modified by this update process.
